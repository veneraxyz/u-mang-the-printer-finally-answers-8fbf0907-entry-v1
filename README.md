Entry for [The Printer Finally Answers](https://make.fun/competitions/u-mang-the-printer-finally-answers-8fbf0907) — one line, in the office printer's own voice, finally explaining the paper jams, the cryptic error codes, and the thumps.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output npx tsx main.ts
```

The program writes exactly one line (1–240 chars, no control characters) to `entry.txt` in the output directory, validates the line before writing, and re-reads the file afterwards to confirm it landed byte-identical.
